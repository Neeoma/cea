Make CEA look like a credible, internationally competitive technology academy.

Explain its courses, training programmes, and learning pathways.

Convert visitors into students through clear enrolment journeys.

Showcase practical cybersecurity training, projects, labs, and student achievements.

Build a community around cybersecurity, ethical hacking, and digital innovation.

HTTPS everywhere.

Multi-factor authentication for administrators.

Database row-level security.

Secure password reset.

Server-side payment verification.

Rate limiting on forms and authentication.

Input validation and sanitisation.

Automated database backups.

Secure file uploads.

Audit logs for administrative actions.

Privacy and data retention controls.

Also consider compliance with the Nigeria Data Protection Act and applicable NDPC requirements.

Never expose payment secret keys, database service-role credentials or API secrets in frontend code.

# 10\. Security requirements

Since CEA operates in technology education, its own website should demonstrate good security practices.

I recommend:

1. HTTPS everywhere.
2. Multi-factor authentication for administrators.
3. Role-based access control.
4. Database row-level security.
5. Secure password reset.
6. Server-side payment verification.
7. Rate limiting on forms and authentication.
8. Input validation and sanitisation.
9. Automated database backups.
10. Secure file uploads.
11. Audit logs for administrative actions.
12. Privacy and data retention controls.

Also consider compliance with the Nigeria Data Protection Act and applicable NDPC requirements.

Never expose payment secret keys, database service-role credentials or API secrets in frontend code.
